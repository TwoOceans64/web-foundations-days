# QuickNotes — Web Foundations Day 1 Assignment

## 📌 Overview
QuickNotes is a simple note‑taking web app built as part of the **Web Foundations** course.  
It demonstrates core HTML5 structure, semantic elements, and validation practices.

## 🗂 Project Structure
```
practice-quicknotes-day1/
├── index.html   # Main page with note input and list
└── about.html   # About page with intro, features, shortcuts, and feedback form
```

## ✨ Features
- Semantic HTML5 structure (header, nav, main, footer)
- Navigation links between pages
- Ordered and unordered lists
- Table for keyboard shortcuts
- Feedback form with labels and required inputs
- Validated at [W3C Validator](https://validator.w3.org/)

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Open the folder in VS Code.
3. Use **Live Server** to launch `index.html`.
4. Navigate between **Home** and **About** using the header links.
